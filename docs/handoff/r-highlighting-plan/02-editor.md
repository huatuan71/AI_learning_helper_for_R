# 对话二提示词

复制下方内容给代码输入组件执行对话，并附共同基线提交号和工作树绝对路径。

---

请实现R语言AI助教的可高亮代码输入组件。阅读适用AGENTS.md和 `docs/handoff/r-highlighting-plan/00-coordination.md`，使用 `codex/r-code-editor` 独立工作树。

先检查 `#code`、app.js、r-file.js及相关浏览器测试中的读取、赋值、文件加载、锁定、草稿和提交行为。新增 `static/r-code-editor.js`，采用原生textarea与高亮展示层叠加，保留textarea原ID、value及编辑数据源。

提供 enhanceRTextarea(textarea, {renderCode})，返回 refresh、setValue、destroy。高亮回调由集成方注入，独立开发阶段可使用纯文本回调，最终集成后用真实R高亮模块复验。

重点处理以下行为。

1. 两层字体、字号、行高、内边距、Tab宽度、换行、水平与垂直滚动一致。长行在编辑区内滚动。
2. 保留光标、选择、撤销重做、粘贴、原生Tab焦点、只读、禁用、聚焦和现有字数验证。
3. 中文输入法组合期间保护原生输入，组合结束后同步高亮。视觉更新只处理展示层。
4. 程序赋值通过setValue或显式refresh同步，列出文件读取、清空、示例填充、旧记录和草稿的接入点。
5. 处理隐藏与展开、容器尺寸变化、移动键盘和长内容。高亮层设置aria-hidden，避免重复朗读。
6. 高对比度或组件失败时恢复可用原生显示，destroy正确取消观察器、事件和未完成绘制。

新增组件样式使用共同前缀及主题变量，基础排版可放 `static/r-code-editor.css`，语法颜色由集成对话的主题统一提供。app.js和r-file.js的最终接入交给对话三，保持文件归属。

使用真实浏览器测试输入、选择和剪贴板、撤销重做、文本不变、长行与滚动对齐、文件赋值、清空、只读、重复挂载和销毁、390px触摸及中文组合事件。实际输入法与真机测试按已完成范围记录。

完成后提交并交付提交号、公开接口与使用示例、所有程序赋值同步位置、样式变量和类名、测试结果、性能及平台限制，以及集成对话需要修改的位置。
