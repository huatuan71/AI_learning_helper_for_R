# 对话三提示词

先把下方内容交给界面与集成对话，准备共同基线后再启动另外两个执行对话。

---

请负责R语言AI助教的全站R代码高亮接入、主题和最终验收。阅读适用AGENTS.md和 `docs/handoff/r-highlighting-plan/00-coordination.md`。

先核对最新main和工作区，将本组说明与需要保留的当前成果保存为共同基线。创建 `codex/r-syntax-core`、`codex/r-code-editor`、`codex/r-highlighting-ui` 独立工作树，回复共同基线提交号与三个绝对路径。你在r-highlighting-ui工作树执行集成。

使用 claude-design skill 沿用现有磨砂界面设计代码主题，使用 playwright skill 完成实际浏览器验收。先扫描所有R代码入口，建立文件及节点接入清单。

1. 新增 `static/r-code-theme.css`，按共同说明统一关键字、函数、字符串、数字、注释和运算符颜色。适配浅色页面、知识详情深色、代码选择、高对比度和打印。
2. 接入统一codeBlock渲染函数，并兼容已有调用。为Markdown传递实际语言，保持流式和最终回答一致。首页示例、明确的R行内片段、旧记录、提交代码、知识详情、复习题、变式题和小结都在清单中验收。
3. 使用代码输入组件增强专用R textarea。对app.js、r-file.js、示例、清空、记录回填、草稿恢复及只读和禁用状态接入refresh或setValue。提交仍从真实textarea读取。
4. 若AI出题已合入，接入题目代码、参考代码及专用代码作答区。若仍在其他工作树实现，将实际统一组件接口和接入清单交接给出题集成对话。
5. 代码复制、记录、文件与接口载荷使用原始字符串。保留代码标题、复制按钮、来源、错误标记和未运行验证标签。
6. 将高亮模块、输入组件、语法依赖和样式加入PWA白名单，协调动态导入、入口和Service Worker版本。下载离线包后复验高亮和编辑。

收到语法核心和输入组件提交号后，审查并合入集成分支，使用两者真实实现进行全流程验收。根据实际新DOM更新过时测试，保留原功能覆盖。

验收不同R语法类别、原文等价、安全文本、未完成流式代码、长回答、代码复制、文件上传替换、10000字符边界、隐藏代码提交规则、撤销重做、中文组合输入、输入与展示滚动对齐、旧记录和草稿恢复。

检查1440px桌面与390×844窄屏、深浅主题、磨砂背景对比度、键盘和无障碍文本。运行实际收集的pytest，以及适当的问答、文件、流式、学习记录、总结、存储和PWA浏览器回归，修复问题后重测受影响范围。

提交前检查密钥、.env、虚拟环境、日志和临时产物。完成集成提交并保留本地服务，交付访问地址、截图、提交号、覆盖清单、测试结果、依赖版本、许可证、性能参数及真实平台和输入法尚待验证的范围。最终合并main和推送按用户后续指令执行。
