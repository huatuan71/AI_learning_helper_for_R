# 对话一提示词

复制下方内容给语法高亮组件执行对话，并附共同基线提交号和工作树绝对路径。

---

请实现R语言AI助教的统一语法高亮核心。阅读适用AGENTS.md和 `docs/handoff/r-highlighting-plan/00-coordination.md`，使用 `codex/r-syntax-core` 独立工作树。

先检查当前原生模块、代码渲染、净化方式和本地vendor依赖。根据共同规划核对Prism官方文档与R语法，固定实际采用版本，将必要的核心及R语法资源封装为本地可用模块，保存许可证、来源和构建说明。

新增 `static/r-highlighter.js`，提供 tokenizeR(source) 和 rCodeFragment(source)。tokenizeR返回受控的type和text，拼接所有text须还原原文。rCodeFragment用文本节点和span构造DocumentFragment，保持textContent等价。分类映射使用固定前缀类名。

分类包含普通文字、关键字与特殊值、函数调用、字符串、数字、注释、运算符和标点。补充R特性并测试优先级，覆盖反引号名称、原始字符串、转义引号、复数或整数后缀、科学计数、NA家族、<-、<<-、->、->>、::、:::、$、@、%in%、%>%、|>、公式和中文标识符。函数类别按调用位置识别，说明词法识别范围。

模型流式返回可能停在字符串、注释或表达式中间，组件须能安全显示未完成代码。解析失败和超长内容返回完整可读原文，并说明触发条件及实际性能阈值。

测试必须验证文本还原、安全DOM、类别、空行与末尾换行、CRLF、Unicode、注释内HTML、脚本字符串、未闭合输入以及长行性能。记录实际设备、样本规模和耗时。

主要提交高亮模块、必要vendor文件、许可证、来源说明及专项测试。全站样式、编辑器和页面接入由另两个对话负责。完成后交付提交号、实际接口、类名与token类别、依赖版本、测试结果、性能限制和接入示例。
