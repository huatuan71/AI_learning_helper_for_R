# 线程二提示词

将下面的提示词完整复制到一个独立聊天。

```text
请实现R语言AI助教的学习概览、自动复习界面、学习小结和难点收藏，并接入现有知识地图与问答记录。

仓库位于 E:\作业2\R语言及其应用\小组作业，项目位于 成员三/ai_tutor。
你的专属分支为 codex/learning-ui。

先读取适用的AGENTS.md，以及 成员三/学习功能实施/00_协作约定.md。按其中的数据结构、模块接口、文件归属和交接要求实现。

使用独立工作树。优先使用当前聊天已分配的工作树。需要自行创建时，可在仓库 .worktrees/learning-ui 创建本分支工作树，并将 /.worktrees/ 加入本机 .git/info/exclude。

使用claude-design skill结合当前真实页面完成设计，并使用playwright skill做真实浏览器检查。沿用项目现有的系统字体、蓝色强调色、浮动磨砂玻璃导航、输入区与对话材质，适配桌面和390×844窄屏。

你的修改范围
- static/app.js、static/index.html、static/knowledge-map.js。
- 新增 static/learning-center.js、static/learning-center.css、static/review-bank.json。
- 新增 tests/browser_learning_center.js、docs/learning-ui.md。

线程一提供 learning-store.js 和 review-scheduler.js，线程三提供 offline.js。它们的接口已经写在协作约定中。你按约定接线，跨线程需求写入交接说明。

一、学习入口

使用可用的claude-design skill，沿用现有浮动磨砂玻璃、系统字体、蓝色强调色与留白层级。新页面优先使用短标签和可折叠的低频设置，桌面与手机均检查实际内容密度。

沿用 /#/history，在“学习记录”内增加“概览、复习、小结、记录”四个页签。导航、刷新、前进后退和键盘访问需要可用，现有对话定位、导出和清空保留可操作入口。

概览展示真实的学习主题数量、复习情况、待复习数量、八个单元进度和最近活动。知识状态使用已浏览、已练习、待复习等可核对标签。独立完成情况来自有效作答。

首次无记录时展示实际空状态和学习入口。页面说明保持简短，详细设置、档案管理和离线资料放进折叠区域。

二、自动复习界面

使用 buildReviewQueue 生成今日任务，默认6题，展示每题简短安排原因。
支持作答、解题提示、参考答案、自评、客观题判分、跳过、提交后继续和刷新恢复。提示使用、提前查看答案与变式完成需要按真实操作传给存储模块。
“熟练完成”使用协作约定规定的证据条件，界面按实际可用题目控制可选评级。

建立单独的 review-bank.json，至少覆盖43个知识点的概念、应用各一题。先读取 data/course.json 及已有补充资料，以真实课程内容编制概念回忆、代码阅读、操作顺序或纠错题。
题目和参考答案携带来源。缺少专门练习答案时使用能从课程解释和示例核对的对照题，并标明改编来源。为部分知识点增加可验证的变式题，用于熟练评级。
开放回答使用自评和参考要点。选择题使用已知正确选项。代码展示保持“未运行验证”。

三、小结

提供今日、最近7天、自选日期范围。按实际学习事件和作答生成主题、课程要点、典型代码、主要易错点和下一步任务。
每项支持返回对应对话或知识点，支持打印或导出文本周报。
离线版本采用课程与记录模板生成，显示生成方式和日期范围。统计口径要能从记录复算。

四、收藏与联动

知识详情增加“加入复习”“收藏”，记录详情浏览。
已完成回答增加收藏入口，收藏记录允许添加和修改个人备注，在复习页中集中展示。
成功问答保存后调用 ingestConversation，启动时调用 migrateLegacy，刷新时从IndexedDB恢复历史。现有对话界面可以分批显示，完整历史由存储模块保留。
旧界面的“清空记录”接 clearConversations。完整学习档案的重置采用单独的明确确认操作。

五、跨平台存储和离线资料入口

实现完整档案导出、文件选择导入、导入结果反馈、错误文件提示、重复导入和重置确认。通过跨平台文件下载及文件选择完成，兼容手机保存到文件应用。
加入“保存离线资料”“更新离线资料”，调用 offline.js 的约定接口，展示实际下载进度和版本，成功后将课程快照交给 saveCourse。
启动时请求原有课程接口，连接失败时读取已保存快照，恢复课程目录、知识详情、复习和统计。联网模型请求继续走现有后端流程。
在index.html添加 /static/manifest.webmanifest 和线程三约定的图标链接。静态资源标记使用 learning-v1。

六、验证与交付

使用playwright skill测试真实学习事件、四个页签、练习评级、提示与答案约束、收藏备注、日期小结、周报导出、旧记录迁移、刷新恢复、导入导出和手机布局。
课程内容、用户答案、备注、文件名和导入内容使用安全文本渲染。检查长代码和长中文在390px宽度的换行、焦点、触摸目标和滚动。
依赖模块尚未合并时，使用测试专用替身验证调用契约，并在交接说明标出端到端待验证项。生产模块使用共享约定的真实接口。

完成后只提交你的归属文件，提交信息使用 feat: add learning center and guided review。最终返回提交编号、桌面和手机截图、真实测试结果，以及需要集成线程处理的具体事项。
```
