# 对话三提示词

先将下方内容复制给负责界面与集成的对话。它准备共同基线后，再启动另外两个执行对话。

---

请负责R语言AI助教“AI学习总结”的界面、分支协调和最终集成验收。先阅读适用的 AGENTS.md 和 `docs/handoff/ai-summary-plan/00-coordination.md`。

先检查当前 `main` 及未提交改动。当前成果含知识地图相机与正圆布局、公共提示玻璃材质和快捷配置入口。核对差异、相关测试、密钥及临时产物，保存已完成成果及本组任务说明为共同基线。为 `codex/ai-summary-api`、`codex/ai-summary-data` 和 `codex/ai-summary-ui` 建立独立工作树，回复共同基线提交号与三个工作树的绝对路径，供用户转交另外两个对话。

你使用 `codex/ai-summary-ui` 工作树。请先检查现有页面和模块，再使用 claude-design skill 沿用项目磨砂玻璃设计实现界面，使用 playwright skill 完成实际浏览器验收。

1. 在“学习记录 → 小结”的现有日期选择旁增加“AI总结”。沿用今日、最近7天和自选范围。模型配置入口复用现有模型设置及公共快捷提示。
2. 提供简短生成说明及“发送内容”折叠预览，显示所用厂商、模型和费用提示。预览与实际请求使用数据对话的同一输入对象。
3. 生成中显示状态及取消入口。处理未配置、过期、无数据、离线、超时、格式错误和服务断开，错误后恢复按钮并保留原有总结。
4. 展示近期重点、需巩固内容和下一步建议，每条观察显示可定位的证据与知识来源。沿用“相关知识”“练习”“返回对话”等短标签，解释正文保持自然。
5. 相同输入默认显示缓存，提供“重新生成”。切换范围和快速操作时隔离请求状态，按原始范围保存结果，当前页面展示对应范围的总结。
6. 提供复制和文本导出，扩展现有小结打印与导出以包含用户当前选择的AI总结，并显示日期、厂商、模型、生成时间和覆盖范围。
7. 刷新和离线可读取已保存的有效总结，数据改变时提示总结对应旧记录。无效证据链接显示缺失状态，避免进入错误的对话。
8. 复用安全文本和现有净化渲染方式，支持键盘、清晰焦点、减少动画与390×844布局。公共提示与菜单的层级继续允许操作导航和模型配置。

主要新增 `static/learning-summary-ui.js`，接入 `learning-center.js`，按需要调整 `app.js` 的模型入口和状态回调。数据模块调用对话二的公开方法，HTTP调用对话一实际完成的契约。

收到另外两个对话的提交号后，审查并合入当前集成分支。核对API字段、模块方法、数据库版本2和档案schemaVersion 2兼容。更新现有测试中硬编码的档案版本，同时保留旧版档案导入覆盖。把新模块加入PWA资源白名单，协调入口版本、动态导入和Service Worker版本，验证旧包更新后刷新可用。
