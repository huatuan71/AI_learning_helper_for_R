# 对话一提示词

将下方内容复制给负责后端的对话，同时给出集成对话准备的基线提交号及工作树绝对路径。

---

请实现R语言AI助教的“AI学习总结”后端。项目根目录包含 `ai_tutor/`，先阅读适用的 AGENTS.md 和 `docs/handoff/ai-summary-plan/00-coordination.md`，以其中的拟新增契约实施。使用集成对话提供的共同基线，在 `codex/ai-summary-api` 独立工作树中完成。

先核对现有结构及 `app/ai/providers.py`、`sessions.py`、`service.py`、`routes.py`、`app/main.py` 和统一错误处理。实现以下交付。

1. 新增 `POST /api/learning/summary`，使用专用Pydantic输入输出模型。详细字段、大小限制、no_data响应和证据规则见共同说明，完成后给出完整请求与响应实例。
2. 复用现有模型会话、密钥、厂商适配器、CallBudget、并发控制和 `run_for_session()`。总结服务使用专用系统提示词和输出校验，调用各适配器的 `complete()`。
3. 使用 `learning-summary-v1` 提示词版本。将学习记录和旧AI回答作为数据，模型生成重点、学习困难、复习建议和下一步行动。已有自评和提示标志要准确表述，模型建议附证据。
4. 从服务端真实课程补充知识标题和必要说明，验证所有知识ID和证据ID。对输入统计做类型与合理性校验，输出中的未知引用必须被拒绝。
5. 网页搜索配置下使用同一模型的普通生成，显式关闭搜索工具。单次输出上限为用户配置与4096中的较小值。计费和用量元数据使用实际返回信息。
6. 无数据时在调用模型前返回 no_data。未配置、会话失效、网络超时、取消、配置变化和格式错误使用项目统一错误结构及现有适用语义。
7. 请求和响应使用 no-store，日志沿用现有脱敏方式，完整学习内容只在本次生成中处理。

主要新增文件为 `app/ai/summary_schemas.py`、`app/ai/learning_summary.py` 和 `app/api/learning_summary.py`，在 `app/main.py` 注册。确需调整公共适配器时保持现有调用行为，并为变化补充回归。

使用 MockTransport 编写专项测试，覆盖三厂商、无数据、输入边界、日期时区、模型与会话错误、搜索关闭、错误引用、超长及无效输出、恶意学习记录、用量、超时和取消。原接口回归必须通过。测试中使用专用总结输出样本，供界面集成对话复用。

完成后提交本分支，回复提交号、实际接口契约、公开服务入口、测试命令和真实结果、适配器变化、供浏览器测试复用的样本及接入说明。用户真实厂商试用结果单独注明测试范围。集成对话负责正式接口说明、最终UI和PWA验收。
