# 对话二提示词

将下方内容复制给负责学习数据的对话，同时给出集成对话准备的基线提交号及工作树绝对路径。

---

请实现R语言AI助教“AI学习总结”的输入整理、缓存和档案兼容。先阅读适用的 AGENTS.md 和 `docs/handoff/ai-summary-plan/00-coordination.md`。使用共同基线，在 `codex/ai-summary-data` 独立工作树中完成。

先核对 `static/learning-store.js`、`review-scheduler.js` 和 `learning-center.js` 中的日期、统计、自评及档案语义。请实现以下交付。

1. 新增 `static/learning-summary-data.js`，公开 `buildSummaryInput(snapshot, period)` 和必要的缓存匹配辅助方法。输入为完整IndexedDB快照，日期范围与IANA时区显式传入，输出遵循共同接口契约。
2. 在本地计算本期统计，保留浏览、学习、作答、自评、提示使用和查看答案的区别。复用现有规则及纯函数，必要时把相同判定提取到本模块并给集成对话说明调用方式。
3. 按真实证据整理最多50条摘录。排序和采样可复现，优先覆盖反复纠错、需巩固作答与本期主要主题，再覆盖近期其他主题。输入不足时如实表达。
4. 对话提问、回答和报错摘录合计每条最多1200字符，总请求最多120 KiB UTF-8。保留稳定证据ID和原始记录定位。首版摘录排除完整代码、个人备注与密钥，文本截断保留合法Unicode字符。
5. 提供准确的 total_evidence_count、included_evidence_count、truncated 和 policy_version。预览与发送共用同一对象，归一化排序后计算SHA-256输入指纹。
6. IndexedDB升级为版本2，新增 summaries。提供保存、读取、查询匹配缓存和删除总结的方法。返回可供UI定位的元数据，公开方法写入分支交接。
7. 完整档案升级至 schemaVersion 2，保留旧 schemaVersion 1 导入。对 summaries 做字段白名单、体积、长度和重复校验，归入原子导入事务。格式损坏时保留原数据。
8. 清空对话时删除引用这些对话的总结，重置档案清除全部总结，跨标签页及时通知。旧页面阻塞升级时沿用可恢复提示。生成失败不能覆盖旧缓存。

总结缓存包含有效响应和定位元数据，输入摘录在本次生成中使用。缓存匹配包含范围、时区、输入指纹、厂商、模型和提示词版本，前端缓存提示词版本与后端 `learning-summary-v1` 对齐。

主要修改 `static/learning-store.js` 并新增数据模块及专项测试。UI、正式接口文档和PWA白名单交给集成对话接入。

测试覆盖空库、无作答、仅浏览、错误后的再次作答、提示与答案标志、日期边界、时区和夏令时、排序稳定、重复记录、Unicode体积、超长截断、指纹变化、旧数据库升级、旧档案导入、完整恢复、重复导入、事务失败、清空和双标签页。真实IndexedDB行为使用现有浏览器测试方式验证。

完成后提交本分支，回复提交号、全部公开方法及示例、迁移和档案格式说明、采样规则、指纹算法、测试命令和真实结果、集成对话需更新的旧版本断言及接入位置。
