# AI出题实施规划

编写日期为2026年11月17日。项目位于仓库根目录 `ai_tutor/`。本组文档约定待实现的AI出题功能。

## 基础与目标

规划时 `main` 的最新提交为 `3399713`，已包含AI学习总结。IndexedDB数据库版本和完整档案schemaVersion均为2，summaries已纳入档案。现有题库位于 `static/review-bank.json`，复习调度使用 `review-scheduler.js`，模型会话、取消和三厂商适配器可以复用。

执行时以核对过的最新项目为基线，保留已交付的AI总结、相机交互和公共磨砂提示。AI总结的原任务文件用于理解已有实现，新出题任务按本组文档协调。

第一版让用户按知识点、课程单元或近期需巩固主题生成一组练习，并完成作答、解题提示、参考答案对照、保存与离线重做。新增“AI出题”入口位于“学习记录 → 复习”，知识详情和AI总结的复习建议可以携带知识ID进入同一入口。

默认生成3题，可选1至5题，难度分为基础、标准和进阶。题型包含单选、简答、代码阅读和代码纠错，默认混合。每批最多涉及3个知识点，综合练习组合2至3个知识点。界面默认只展开知识范围和出题按钮，其余设置放入折叠区。

每道题展示“AI生成”标识、课程依据和题目。用户可写答案、查看提示、锁定答案，再对照参考答案。提前查看提示或答案会记录辅助标志。选择题显示与AI参考选项的匹配情况，简答和代码题提供自评。参考答案包含解释及必要的R代码，代码使用“未运行验证”标签。

AI练习结果单独显示练习次数、主题和自评记录。现有课程题库和复习等级使用现有算法。第一版通过既有 exercise_view 学习事件记录AI题目的浏览，现有总结能看到相应主题。AI自动点评、把AI作答证据纳入总结以及影响掌握等级的规则，作为后续版本任务。

## 拟新增接口

使用 `POST /api/learning/exercises`，一次JSON请求返回完整的一批题目、提示和参考答案，适用于自学练习。前端控制答案默认折叠和锁定作答的教学流程。

请求示例采用以下结构。

```json
{
  "schema_version": 1,
  "knowledge_ids": ["K06"],
  "count": 3,
  "difficulty": "basic",
  "formats": ["choice", "short_answer", "code_reading", "code_fix"],
  "recent_prompts": []
}
```

knowledge_ids为1至3个唯一的真实知识ID。difficulty使用 basic、standard或advanced。formats为1至4种不重复题型。recent_prompts最多10条、每条最多300个Unicode码点，用于减少近期重复题。请求总量最多32 KiB UTF-8，额外字段拒绝。

用户选择课程单元时，前端从单元中选择或推荐最多3个知识点，并在发送前显示实际范围。近期需巩固主题由本地规则推荐，依据最近7天的需重学、提示完成、到期卡片和近期学习情况。无记录时提示选择知识点，推荐原因描述实际记录。

后端从43个真实知识点提取解释、语法、示例、易错点及已有错误案例，构建有界课程上下文。由服务端决定本批题型和知识点分布，验证模型产出符合请求数量、难度、题型范围，并让所有选中知识点至少在一题中出现。数量少于知识点数时允许一道综合题覆盖多个知识点。

成功响应包含 request_id、status、mode、generation_id、generated_at、provider、model、prompt_version、knowledge_version、usage、duration_ms和questions。status为ok，mode为ai，提示词版本为 `learning-exercise-v1`。

每道题有以下字段。

| 字段 | 约定 |
|---|---|
| `id` | 服务端生成的稳定题目ID，使用 `aiq:` 前缀 |
| `knowledge_ids` | 本题对应的真实知识ID，属于本次选定范围 |
| `learning_type` | concept或application |
| `format` | choice、short_answer、code_reading或code_fix |
| `difficulty` | 与用户选择一致 |
| `prompt` | 非空题干，最多1200个Unicode码点 |
| `code` | 可选题目代码，最多2000码点 |
| `choices` | 单选题恰好4个非空、互不重复的选项，其他题型使用空数组 |
| `correct_index` | 单选题0至3，其他题型为null |
| `hints` | 1至2条逐步提示，每条最多200码点 |
| `reference_answer` | 参考答案及解题要点，最多1600码点 |
| `solution_code` | 可选参考代码，最多3000码点 |
| `explanation` | 参考答案的解释，最多1000码点 |
| `source_refs` | 由服务端根据知识ID补充的真实课程出处 |
| `execution_status` | 固定为not_executed |

generation_id、题目id、课程出处和运行状态由后端填写。模型输出使用专用结构校验，避免把课程来源交给模型编造。题干、选项和提示满足必要的教学分工，答案与解释一致，批内按规范化题干及代码查重。错误或缺失题目按失败返回，界面保留上一批有效题目。

通过当前模型设置的后端会话生成，搜索配置调用普通生成并关闭搜索工具。输出预算取用户设置与8192的较小值，生成使用现有有界请求预算和并发控制。格式失败、预算不足、会话到期、取消、模型配置变化及上游错误沿用统一错误结构，并提供可理解反馈。

代码阅读题优先使用小型、可推导的数据。涉及随机数时明确种子或改为解释行为。代码纠错题给出足够的问题背景及预期目标。外部文件依赖、包依赖和预期输出要明确，运行标记依据实际执行能力填写。

## 本地数据和作答约定

数据库升级至3，新增 aiExercises 和 aiExerciseAttempts。完整档案schemaVersion升级至3，支持版本1、2导入，缺失新增集合按空数组处理。保留已有 summaries 的校验、缓存和导出行为。

aiExercises保存服务端有效题目、生成批次、请求范围、厂商模型、来源和时间。每道题保存可刷新恢复的当前作答草稿，含答案、选择项、阶段、提示及答案使用标志。题目正文和来源在有效保存后固定，重新出题生成新批次。

aiExerciseAttempts保存独立的作答ID、题目ID、UTC时间和IANA时区、锁定答案、选择项、自评、辅助标志、参考匹配结果及评分来源。自评使用 need_review、assisted、independent。锁定前使用提示或查看答案时，最终记录至少保留assisted标志。模型参考选项比对使用 assessment_source为ai_reference_match，主观题使用self。

作答依次经历草稿、锁定、自评和保存。锁定时保存辅助标志快照，之后查看答案也保留实际查看状态。刷新保持当前阶段，保存失败重试沿用相同ID、答案、时间和评级。再次作答创建新的作答ID。双标签页对同一ID提交时幂等，写入作答及更新草稿阶段使用一个事务。

本轮AI练习作答保存在独立集合。练习区统计直接依据此集合，显示自评与参考匹配的实际含义。现有 attempts 中由课程题产生的调度证据继续按原规则处理。题目首次显示时按每个关联知识ID写入稳定ID的 exercise_view 事件，重复打开同题复用事件ID。

建议公开 `buildExerciseRequest(snapshot, options)`、`recommendExerciseKnowledge(snapshot, options)`，以及learningStore的题目批次保存、查询、草稿保存、作答提交、列表和删除方法。最终签名由数据对话写入交接，接入者使用同一实现。

缓存最多200道AI题目和2000条作答，输入和新档案继续遵守20 MiB上限。达到容量后提示用户导出或删除旧练习。删除一道题时在同一事务删除其草稿和作答。重置个人档案清除新增集合，清空对话保持既有语义。导入时验证题目、选项、来源、作答关联及状态，冲突合并采用明确、稳定的时间与ID规则，全部写入通过事务完成。

题目和作答导入后可以离线阅读、练习、查看答案及自评。密钥继续使用现有模型会话管理，生成过程中只提交配置范围和近期题干。

## 界面与联动

学习记录复习页包含“今日复习”和“AI练习”入口，首次进入AI练习显示选题范围与“AI出题”。知识详情和AI总结建议携带知识ID打开同一练习区域。保留五个顶部主栏目。

快捷标签使用AI出题、重新出题、解题提示、参考答案、锁定答案、保存作答、重新作答、内容来源和复制代码。AI题目使用醒目的简短生成标识。界面沿用现有磨砂玻璃、字号、按钮和移动布局。

未配置和配置到期均提供“配置模型”。生成中显示状态及取消，切换页面停止当前生成并保留草稿和旧题。取消后的迟到响应不覆盖当前批次。多次点击、范围变化及重新出题由任务ID隔离。

## 验收标准

- 三厂商模拟上游返回合法题目，搜索关闭，生成数量及知识覆盖正确。
- 输入校验、未知知识点、空内容、重复选项、错误参考索引、重复题、伪造来源、超长或无效JSON均有明确处理。
- 保留参考题和代码的AI生成与未执行状态，质量检查区分结构验证和人工教学审阅。
- 题目、答案、文件名及代码安全渲染，恶意内容和提示词注入样本经过测试。
- 旧数据库1、2升级至3，旧档案1、2导入、新档案完整恢复、去重、原子失败、双标签页、删除和重置通过测试。
- 生成、取消、配置、作答、提示、提前看答案、锁定、自评、重试、刷新恢复、离线练习和来源跳转通过真实浏览器测试。
- 知识详情和总结建议能进入正确知识范围，练习统计与课程掌握度计算的语义准确。
- 在1440px桌面及390×844窄屏检查布局、键盘焦点和磨砂提示。Android、iOS、macOS真机验证按实际完成情况记录。
- 执行实际收集的pytest、算法与数据测试，以及适当的浏览器、存储、PWA和AI总结回归。正式接口说明更新实际实现和测试过的内容。
- 最终交付集成提交、操作地址、截图、测试结果、迁移方法和真实厂商试用范围。
