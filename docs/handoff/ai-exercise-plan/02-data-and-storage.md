请实现R语言AI助教“大模型出题”的范围推荐、题目存储、作答草稿及档案兼容。先阅读适用AGENTS.md和 `docs/handoff/ai-exercise-plan/00-coordination.md`，使用 `codex/ai-exercise-data` 独立工作树。

检查当前学习数据库版本2、完整档案版本2、AI总结保存、课程题作答和复习调度。新增 `static/ai-exercise-data.js`，扩展 `static/learning-store.js`，完成以下交付。

1. 提供 `buildExerciseRequest(snapshot, options)` 和 `recommendExerciseKnowledge(snapshot, options)`。显式支持知识选择、课程单元、近期需巩固范围和2至3知识点综合练习。推荐按可复验的本地规则，返回实际依据，无数据时让用户选题。
2. 使用近期需重学、提示完成、到期和学习记录推荐范围，按稳定顺序确定结果。生成请求只包含契约允许字段，近期题干最多10条并遵守Unicode与体积上限。
3. 数据库升级至3，新增 aiExercises 和 aiExerciseAttempts。保存有效题目批次、来源、草稿和阶段，公开查询、更新草稿、锁定、自评提交、列表与删除方法。
4. 记录提示使用、提前看答案、锁定时辅助状态、自评、参考选项匹配和评分来源。锁定后刷新状态恢复，保存失败重试沿用同一作答载荷。新增作答与草稿更新通过一个事务提交，双标签页同ID提交去重。
5. AI练习的作答和统计使用新增集合。首次显示题目时按知识ID写入稳定ID的exercise_view事件。现有总结和课程调度的原字段、版本语义要通过回归验证。
6. 完整档案升级至schemaVersion 3，兼容版本1、2导入。对题目、来源、引用、作答和草稿做严格校验，合并、去重和失败回滚使用原有事务机制。保留summaries。
7. 题目最多200道，作答最多2000条，档案上限20 MiB，容量达到时提供可理解错误。删除题目时清理关联作答，重置个人档案清除新增数据，清空对话保持既有语义。

测试无记录、近期范围、时区和夏令时、推荐稳定性、去重、字符与体积、草稿阶段、提示标志、重复保存、事务失败、两个旧版本升级、三个版本档案、双标签页、删除、重置及离线读取。

完成后提交并交付提交号、公开方法签名及示例、推荐规则、状态机、迁移和合并规则、实际测试结果，以及界面与PWA接入位置。UI和正式接口说明由集成对话统筹。
