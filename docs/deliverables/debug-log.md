# 1.2.0调试记录

## TestClient运行基线

受限沙箱运行pytest在首项资料检查通过后停滞。相同虚拟环境在普通本机权限下完成原有55项测试，最终完整回归为136项通过。排查期间采用有时限的复现，保留现有依赖版本。

## 测试状态恢复

pytest对动态属性的恢复与Starlette State的自定义属性存储存在差异，初版测试夹具在结束时删除了原有应用状态。夹具改用State底层映射的setitem恢复，现已验证测试间隔离及完整课程回归。

## 取消在途请求

浏览器首次取消后，下一次提问曾收到SESSION_BUSY。HTTP装饰器生成的中间件影响了断开事件传递。请求编号中间件改为纯ASGI形式，上游调用同时监视浏览器断开与会话配置清除。浏览器已验证取消后可再次提问，后端测试验证清除配置时任务取消并释放并发名额。

## 视图切换

快速切换页面时，View Transition的跳过和超时可能产生Promise拒绝。补充ready及finished的拒绝处理后，正常转场、减少动画和键盘操作完成浏览器回归。

## 地图专项断言

原文件专项脚本仍包含二维有界画布、漂浮动画和旧侧栏的断言。更新为当前Three.js对象、标签、筛选和覆盖面板行为，文件读取与提交专项继续运行，58项通过。

## 所有提问返回结构或引用校验失败

用户反馈DeepSeek连接成功后，任意提问均显示结构或引用校验失败。原日志只记录HTTP状态和耗时，SSE错误发生在响应开始之后，因此HTTP状态为200，具体校验原因被丢弃。

代码检查复现了提示词示例与校验结构不一致。示例展示summary等内部字段，校验器要求answer对象与knowledge_ids数组。原测试夹具固定使用完整结构，遗漏了平铺字段的模型输出。

提示词版本更新为tutor-v1.2.0-r3，提供完整JSON示例、JSON Schema和本轮允许的知识编号。解析阶段兼容平铺字段、字符串answer、可选空值及辅助追问数量差异。正文代码片段与代码字段中的R下标表达式单独处理，正文引用继续与实际搜索来源核对。

自动修复请求带上失败字段与错误类型。初次及修复失败的日志包含请求编号和输出结构摘要，排除原始问题、回答、代码和Key。页面展示具体失败字段及请求编号。

新增回归使用三家厂商的普通HTTP及流式格式，最终192项后端测试、189项浏览器检查通过。服务已重启至修复版，前端资源标记为20261115.6。用户原始上游响应未留存。2026年11月15日，用户重新配置Key后反馈DeepSeek已正常回答。

## 回答内容切分与代码衔接

用户截图显示安装问题中突然出现统计代码，工作目录回答的同级方案被追问按钮分开。核查发现模型按摘要、步骤和单个代码字段生成，前端抽取摘要首句、显示前三个步骤与代码，再把剩余内容放到深入讲解。普通请求还统一携带hint参数。

新协议以content_markdown保存连续正文，来源、追问和问题定位保持结构化。提示词要求根据问题决定是否提供代码，每段代码交代用途、运行位置和预期现象。同级方案完整组织，代码跟随对应解释。前端使用同一个Markdown渲染过程展示流式草稿与最终答案，追问按钮移至回答末尾。旧记录按完整摘要和全部步骤展示。

普通问答的模型输入省略teaching_mode。练习题显式采用hint或solution，提示模式清除围栏答案代码，参考答案保留完整代码。历史发送连续正文，保留原有总预算裁剪。

Marked 18.2.0与DOMPurify 3.4.17随项目本地提供，发布包经过sha512摘要核验。正文净化、链接协议、凭据URL过滤、代码复制和网页引用通过浏览器检查。

最终208项后端测试、207项浏览器检查通过，自动厂商调用使用模拟HTTP。2026年11月15日，用户重新配置DeepSeek后反馈新版展示正常。前端资源版本为20261115.7。
